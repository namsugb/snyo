# UI Rules

## Responsive Strategy

- Design mobile-first by default.
- Treat a phone viewport as the primary experience and make sure each section reads comfortably with one-handed scrolling.
- Expand spacing and multi-column layouts only when the screen size clearly supports it.

## Required Sections

The invitation should include these sections unless explicitly changed:

- Hero or cover section with the couple's names, wedding date, and a strong emotional first impression
- Greeting or invitation message
- Wedding date section with a calendar-style visual
- Venue or location section
- Gallery section
- Photo upload section for guests to upload wedding-day photos

## Layout Direction

- Structure the page like a story, not like an app dashboard.
- Separate sections clearly, but keep the overall page flow soft and continuous.
- Use full-width stacking on mobile, with carefully controlled spacing between sections.
- On larger screens, preserve the mobile emotional flow instead of turning the page into a dense grid.

## Gallery Direction

- Use `design/reference/gallery.jpg` as the primary gallery reference.
- The gallery should feel like a polaroid photo spread or scrapbook arrangement.
- Slight rotation, layered positioning, caption-like details, or paper-frame styling are appropriate when they do not hurt readability.
- The gallery should still remain touch-friendly and responsive on mobile.

## Motion Direction

- Motion should feel gentle, romantic, and handmade.
- Add a subtle alternating animation inspired by `movingimage1.png` and `movingimage2.png`.
- This animation can be used for headline lettering, decorative copy, or character-like imagery so the element feels softly alive.
- The effect should be small in amplitude and loop calmly, not bounce aggressively.
- Avoid heavy parallax, large transforms, or distracting motion that competes with the invitation content.

## Components

- Buttons, cards, and section containers should feel soft and tactile.
- Corners can be slightly rounded, but the page should not feel overly glossy or app-like.
- Use frames, paper-like surfaces, tape-like accents, or caption styling only when it helps the invitation concept.
- Upload UI should feel friendly and simple, with clear instructions for guests.

## Content Presentation

- Prioritize emotional readability over information density.
- Long copy should remain breathable with comfortable line height and margin.
- Dates, names, and place information should be prominent and easy to find quickly.
- Decorative elements should support the core wedding information, never bury it.
