# Content Sections

## Core Principle

This website should function like a wedding invitation first, with supporting interactive sections added in a natural order.

## Recommended Section Order

1. Hero cover
2. Greeting message
3. Wedding date and calendar
4. Venue and location
5. Gallery
6. Guest photo upload

## Section Guidance

### 1. Hero Cover

- Introduce the couple immediately.
- Present the wedding date prominently.
- Create a strong emotional first impression with romantic styling and key imagery.

### 2. Greeting Message

- Include a warm invitation message similar to a traditional wedding greeting.
- The tone should feel heartfelt and personal.
- The text block should be readable on small screens and visually framed like a note or letter if appropriate.

### 3. Wedding Date And Calendar

- Show the wedding date clearly.
- Include a calendar-style visual that highlights the wedding day.
- This section should feel commemorative, not purely functional.

### 4. Venue And Location

- Include the venue name, address, and any helpful visit guidance.
- The location should be easy to scan quickly on mobile.
- Map links or location actions can be added later, but the section should already be designed to support them.

### 5. Gallery

- Use a polaroid-inspired presentation based on `design/reference/gallery.jpg`.
- The gallery should help tell the couple's story and reinforce the emotional tone of the invitation.
- Photos can appear layered, tilted, framed, or captioned as long as the layout stays clean and touch-friendly.

### 6. Guest Photo Upload

- Include a section where wedding-day photos can be uploaded by guests.
- The upload experience should feel simple, welcoming, and clearly explained.
- This section should look like part of the invitation, not like a generic file-upload form.

## Optional Enhancements

- Short captions or handwritten notes between sections
- Small decorative animated text or character elements inspired by `movingimage1.png` and `movingimage2.png`
- Subtle dividers, paper textures, tape effects, or keepsake-style framing
