# Wedding Design System Draft

This folder is the working design source of truth for this project's UI-related Codex tasks.

The project is a mobile-first wedding invitation website. Designs should feel intimate, warm, handwritten, photo-driven, and gently animated rather than corporate or app-like.

Use these files as follows:

- `brand-feel.md`: describes the emotional tone and overall impression of the wedding invitation.
- `ui-rules.md`: defines responsive layout, section composition, gallery style, motion, and required content blocks.
- `typography.md`: defines type mood, handwritten accents, and text hierarchy.
- `colors.md`: defines the main wedding palette and recommended usage.
- `content-sections.md`: defines the expected invitation sections and what each section should communicate.

Use the `design/reference` folder alongside these documents:

- `gallery.jpg`: reference for the photo gallery composition and polaroid mood.
- `mood1.jpg` and `mood2.jpg`: reference for overall atmosphere and handwritten styling.
- `movingimage1.png` and `movingimage2.png`: reference for subtle alternating-motion effects on text or character imagery.

These files are temporary drafts and should be refined as the invitation concept becomes more specific.
