# Design Reference Rules

When working on any UI, UX, layout, styling, copy structure, or visual design task, review the `design` folder first and use it as the project source of truth.

This project is a wedding invitation website built primarily for mobile-responsive viewing. The visual direction should follow the references in `design/reference` and the rules in `design/design-system`.

- Use `design/design-system` for the intended wedding invitation mood, content structure, UI rules, typography, motion, and color guidance.
- Use `design/reference/gallery.jpg` as the main reference for the polaroid-style photo gallery direction.
- Use `design/reference/mood1.jpg` and `design/reference/mood2.jpg` as references for the handwritten, warm, romantic visual mood.
- Use `design/reference/movingimage1.png` and `design/reference/movingimage2.png` as references for subtle repeated animation that makes text or character imagery feel gently alive.
- Prefer mobile-first layouts, then scale up cleanly for tablet and desktop.
- If project-specific design guidance conflicts with generic defaults, follow the guidance in the `design` folder.
